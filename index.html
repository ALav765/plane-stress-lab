Mesh convergence

A result is only trustworthy once it stops changing as the mesh is refined. This re-solves the current problem on finer and finer meshes. The Sleipner A platform was lost in 1991 after a finite element model understated stresses, and a coarse mesh is the classic way that happens.

Limits

  • Linear elastic only. Yielding is flagged through the safety factor, not simulated.
  • Fixed supports create an artificial stress singularity at the wall of the cantilever, so peak stress is read one beam depth away.
  • Plane problems only, with a fixed set of parametric shapes. No free-form drawing.
  • The Comet and Sleipner cases are simplified 2D lessons, not reconstructions of the real structures.
